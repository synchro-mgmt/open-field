# open-field 🌍

**命のフィールドを世界に開く**

株式会社シンクロニシティ・マネジメントの公開ドキュメントポータル。

## 構造

LDM（Life Design Method）太陽系モデルを反映したフォルダ構造：

- **ldm/** — LDM（太陽）：コアメソッド・ロードマップ・レポート
- **earth-journey/** — アースジャーニー（入口＆最深部）
- **synchro-juku/** — シンクロ起業塾（ビジネス応用）
- **oto/** — OTO（音×サイエンス×シャーマニズム）
- **publishing/** — 出版（LDMを世界に広げる）
- **agent-team/** — エージェントチーム紹介
- **team-manual/** — 業務委託チーム向けマニュアル
- **vision/** — 会社ビジョン・コンセプト
- **dashboards/** — ライブダッシュボード・進捗可視化
